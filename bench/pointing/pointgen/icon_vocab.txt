# What people call icon-only controls. One drawing per line:
#
#   group | names | surfaces | noun phrases | action phrases
#
# group     icons of one group mean the same thing, so a screen shows at most one of them
# names     the drawing in each icon set. Bare names are Lucide (alternatives separated by "/",
#           the first that exists is used); h: Heroicons, t: Tabler, m: Material Symbols,
#           s: Apple system symbols (rendered on a Mac, see docs/ICON_SET.md)
# surfaces  where it is typically found: t toolbar, s sidebar, m menu bar, b tab bar (default ts)
# nouns     ";"-separated, written without the leading "the": name of the thing or its look
# actions   ";"-separated verb phrases the control really stands for (may be empty)
#
# Used by pointgen/iconscreens.py. An icon is only drawn by the split that owns its glyph.
